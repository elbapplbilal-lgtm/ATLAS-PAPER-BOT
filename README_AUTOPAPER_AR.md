## شنو كيدير المحرك الجديد

1. يقرأ `/fapi/v1/exchangeInfo` لاختيار أسواق USDT Perpetual المتاحة.
2. يقرأ جميع إحصاءات التداول خلال 24 ساعة لترتيب الأسواق من حيث سيولة التداول الظاهرة.
3. يرشّح **أعلى 20 زوج** بشرط حجم تداول اسمي ≥25 مليون USDT. هادي **ماشي دراسة شاملة لكل زوج**؛ السوق كله كيتصفّى بأرقام السيولة، والشموع كنجلبوها غير للمجموعة المنتقاة.
4. يقرأ آخر 300 شمعة 15m وآخر 300 شمعة 1h من API العام، ويستخدم الشموع **المغلقة فقط**.
5. يشغّل 6 تأكيدات `strategy_v2.py`، ويرتب الإشارات المؤهلة بمؤشر ADX وحجم التداول النسبي. هاد الترتيب ماشي نسبة احتمال الربح ولا نموذج ذكاء اصطناعي مدرب.
6. يفتح **صفقة ورقية** واحدة فقط في كل لحظة، حتى **خمس محاولات افتتاح يومياً كحد أقصى**. إذا ما لقا حتى إشارة صحيحة، **صفر صفقات** طبيعي ومفضل.
7. في المحاكاة: **رافعة 3x معزولة افتراضياً**، لا يتجاوز الهامش النظري 10% من الرصيد (تعرض اسمي أقصى 30% من الرصيد)، مخاطرة مستهدفة 0.5% لكل صفقة، توقف فتح صفقات إذا هبط الرصيد المحقق 2% من رصيد بداية اليوم.
8. يخرج افتراضياً عند وقف الخسارة، الهدف 1.8R، أو بعد 32 شمعة؛ إذا لمس الهدف والوقف بنفس الشمعة يعتبر الوقف أولاً. يحسب رسوم 0.04% في كل اتجاه وانزلاقاً مفترضاً 0.03%.
9. يحفظ حالة الصفقات والمحاولات ليتجنب الدخول المكرر في نفس الشمعة.

**محدودية كبيرة:** نموذج المحاكاة لا يحسب التمويل Funding، التصفية، فشل وقف الخسارة في المنصة، قيود كمية التداول، التأخر أو انقطاع الخدمة. خطر خسارة أكثر من 0.5% ما زال ممكناً، خصوصاً في العقود الحقيقية.

## شنو ما كيديرش

- ما فيه لا API Key، لا Secret، لا طلبات `POST`، لا صلاحية الحساب الحقيقي، لا تنفيذ شراء أو بيع على Binance.
- ماشي نموذج ML مدرّب؛ هو آلية قرار آلي مبنية على مؤشرات V2.
- ما كاينش مبرر تقول «الروبوت كيتداول بنفسه 24/24» حتى نلقاو خادم مناسب ومسموح ونجربو التنفيذ في Demo.
- ما خاصش أي واحد يغير عنوان السوق العام ليربطو بتداول حقيقي مباشرة.

## فبيئة Python موثوقة وعلى شبكة مدعومة

```bash
python -m unittest discover -s tests -v
python atlas_autopaper.py --mode once
# loop غير بعد التأكد من صلاحية الاتصال ومن مراقبة الجهاز:
python atlas_autopaper.py --mode loop
```

النتائج الورقية تتخزن في `data/autopaper_state.json` و`data/autopaper_report.json`، وتطلب بيانات عامة فقط. تنفيذ هاد الخطوات على GitHub Actions **ماشي مضمون ولا مفعّل آلياً**، لأنه سبق وقع حظر الاتصال (HTTP 451).
