# ATLAS — Futures Demo (بفلوس افتراضية فقط)

## شنو الفرق؟

- `bot.py`: محاكاة محلية بدون حساب Binance. ما كتفتح حتى صفقة فبورصة Binance.
- `demo_trader.py`: كيتصل **حصرياً** بـ `https://demo-fapi.binance.com` وكيقدر، من بعد إذن صريح، ينفذ أوامر من حساب **Binance Futures Demo Trading**. عمره ما كيستدعي عنوان Binance الحقيقي.
- هادشي ماشي تدقيق إنتاجي وما كاين حتى ضمان أن الإشارات رابحة أو أن جميع الطلبات غادي تنفذ بلا أخطاء.

## إجراءات الأمان

- شبكة DEMO فقط، حتى ملي كتكون المفاتيح مضبوطة.
- BTCUSDT فقط في هاد الإصدار. التحليل الجديد ATLAS V2 كيحتاج **شموع مغلقة من 15 دقيقة ومن ساعة** مع اتجاه موحد، RSI، ADX، حجم التداول، واختراق أو ارتداد واضح. خاص 6/6 تأكيدات، ولا صفقة بلا تأكيد.
- يعطّل أي فتح جديد إذا كاينة صفقة مفتوحة، أو أوامر معلقة أو شرطية، أو كان الحساب في Hedge Mode.
- رافعة 1x وIsolated. كيسمح بحد أقصى 10% من المحفظة الافتراضية كحجم صفقة، ومخاطرة وقف مستهدفة حتى 0.5% ولكن ممكن الانزلاق يتجاوزها.
- ما أكثرش من **5 صفقات افتتاحية فاليوم** (مشروع تجريبي فقط)، والتوقف بعد هبوط 2% من رصيد البداية اليومية (مؤشر تقريبي، حسب المحفظة اللي كيقراها).
- كيبعث أمر وقف على البورصة من بعد ملء الصفقة. إلا فشل الوقف، كيحاول يسد الصفقة فوراً. **ممكن يقع فشل حتى هنا، لذلك ما يستعملش نهائياً فحساب حقيقي**.
- إذا تْقطع الاتصال، البوت كيتوقف وما كيعاودش إرسال أمر شراء مجهول الحالة تلقائياً.

## خطوات الربط (كاملين من الهاتف)

1. فـ Binance اختار **Futures Demo Trading**. سجل فالحساب التجريبي ومن **API Management** أنشئ **API key خاص بالتجريبي فقط**؛ المرجع الرسمي: https://www.binance.com/en/support/faq/detail/ab78f9a1b8824cf0a106b4229c76496d.
2. فـ GitHub، داخل المستودع `ATLAS-PAPER-BOT`، مشي **Settings → Secrets and variables → Actions → Secrets**. أضف `BINANCE_DEMO_KEY` و`BINANCE_DEMO_SECRET`. **لا ترسل المفاتيح فالدردشة، ولا تحطها فملفات المستودع العمومي، ولا تستعمل مفاتيح الحساب الحقيقي.**
3. باش تسمح بتداول DEMO فقط، داخل **Actions → Variables** زيد `ENABLE_ATLAS_DEMO` بقيمة `YES` من بعد ما تجرب الحساب وتوافق على تشغيله. قبلها البوت ما غاديش يرسل أوامر Demo.
4. راجع **Settings → Actions → General → Workflow permissions** وخلي `Read and write permissions` إلا كان GitHub كيسمح؛ لولاها ممكن ما يحتافظش بالذاكرة ديال المحاولات، وخص توقف الجدولة حتى تتصلح.
5. فتح **Actions → ATLAS Binance Futures DEMO → Run workflow**. وإلا كان التفعيل موجود، من بعد كيتجدول تلقائياً كل 15 دقيقة تقريباً، **لكن GitHub Actions يمكن يتأخر أو يتوقف**، وماشي خادم تداول مضمون.
6. باش توقف الخدمة: بدّل `ENABLE_ATLAS_DEMO` إلى `NO` أو عطل Workflow، وراجع بنفسك أي صفقات DEMO مفتوحة؛ إيقاف البوت بوحدو ما كيسدّهاش.

**مهم:** أي خادم تشغيل خارج نطاق GitHub Actions، أو أي انتقال إلى حساب حقيقي، يحتاج اختبار أوسع وقرار منفصل. ما تغيرش `DEMO_HOST` مطلقاً.

## ATLAS V2: تحليل السوق ثم قرار عدم التداول أو التداول (تحديث 17 أكتوبر 2026)

- الملف `strategy_v2.py`: إستراتيجية مع شروط تصفية صارمة **تاريخية القواعد** (rule-based)، ماشي ذكاء اصطناعي كيتنبأ بالمستقبل ولا «عبقري مضمون الربح».
- كيجمع **6 تأكيدات**: اتجاه ساعة (EMA50/200 وميل EMA50)، اتجاه ربع ساعة (EMA20/50/200)، RSI، ADX، حجم الشمعة مقارنة بـ20 شمعة سابقة، واختراق 12 شمعة أو ارتداد مؤكد من EMA20.
- التداول ممنوع إذا الشموع ناقصة أو قديمة، الإطارين غير متوافقين، الشمعة كبيرة بزاف، الحجم ضعيف، أو تأكيد ناقص. وقف الخسارة يرتبط بـ ATR، والهدف النسبي المستهدف **1.8R** قبل الرسوم والانزلاق.
- **5 صفقات هو العدد الأقصى للمحاولات اليومية، وليس عدد صفقات ناجحة مضمونة أو معدل نجاح 100%.**
- استراتيجية V2 خاضعة لاختبارات وحدات وهمية بـ GitHub Actions؛ **ما زال ما وقع حتى تنفيذ صفقات DEMO موثّقة**، ولا تجربة سوق حقيقي ولا backtest قابل للاعتماد على بيانات كافية. خاص اختبار إضافي للحالات الاستثنائية وتطابق واجهة Binance.
- `DEMO_HOST` ما زال ثابتاً على `https://demo-fapi.binance.com`. التداول التلقائي في Workflow باقي موقوف افتراضياً، وخادم GitHub أعطى **HTTP 451** على الطلب العمومي بدون مفاتيح. **تغيير المفاتيح لا يحل حظر الشبكة**.
- عند استعماله مستقبلاً، ممكن تتجاوز الخسارة الفعلية حد المخاطرة المحدد بسبب الانزلاق، رفض أوامر وقف الخسارة، الانقطاع أو فجوة السعر. لا تربط مفاتيح حقيقية نهائياً بهذه النسخة.
