# ATLAS — بوت تداول افتراضي + وصلة Binance Futures Demo

هاد مشروع **حقيقي بالكود**. ملف `bot.py` كيراقب شموع Binance Futures العامة، كيحلل 12 زوج، وكيحل وكيغلق **صفقات افتراضية فقط** بلا مفاتيح API. ملف `demo_trader.py` إضافة منفصلة كتسمح بأوامر **على Binance Futures Demo فقط** بعد تأكيد التفعيل وربط مفتاح Demo، وعمرو ما يرسل أمر لحساب حقيقي. شوف `README_DEMO_AR.md`.


## جديد: فحص الحساب الحقيقي بالقراءة فقط

أضفنا `live_readonly.py` باش نحضّرو ربط Binance Futures الحقيقي **للقراءة فقط**، ما فيه لا شراء ولا بيع ولا إلغاء. اختباراته الوهمية دازت، ولكن **مازال ما اتصل حتى بحساب حقيقي، وما نستعملوش مفاتيح API الحقيقية داخل GitHub أو Railway أو الدردشة**. راجع [دليل الأمان والربط](README_LIVE_READONLY_AR.md). **ماشي روبوت تداول حقيقي**؛ التداول الحقيقي ما زال غير متاح فهاد المشروع.

## شنو كيعمل؟

- كيجيب بيانات الشموع الحقيقية من `https://fapi.binance.com/fapi/v1/klines` على إطار 15 دقيقة. ما كيتصلش بحسابك الخاص.
- كيشوف مؤشرات EMA 9/21/50 وRSI وATR؛ كيقرر دخول LONG أو SHORT بشكل تجريبي.
- كيدير إيقاف خسارة وربح بهدف 1.8 مرة مسافة الستوب؛ إلا ضرب الهدف والستوب فنفس الشمعة كيحسب الستوب أولاً احتياطاً.
- الرصيد الافتراضي كيبدأ بـ5000 USDT؛ مخاطرة مستهدفة 0.5% للصفقة؛ 3 صفقات مفتوحة كحد أقصى؛ بعد خسارة يومية محققة 2% كيوقف فتح صفقات جديدة حتى النهار الجاي.
- كيحسب رسوم وتزحلق افتراضيين، وكيحفظ البيانات فـ `data/paper_state.json` وتقارير `data/summary.json` و `data/summary.csv`.
- باك تيست للمئات من الشموع والصفقات التاريخية (عدد الصفقات الفعلي حسب الإشارات ماشي مضمون)؛ وفيه خيار اختبار أوفلاين بأسعار **مصطنعة وموسومة بوضوح**.

## التشغيل على Python 3.10+ (هاتف Termux أو حاسوب أو خادم)

**بلا أي مكتبات Python إضافية** (هاد الأوامر خاصة بمحاكاة `bot.py` فقط):

```sh
python bot.py --mode offline-test
python bot.py --mode backtest
python bot.py --mode once
python bot.py --mode loop
```

للتشغيل لزوج واحد فقط: `python bot.py --mode loop --symbols BTCUSDT`.

### الفرق بين الأنماط

- `offline-test`: كيختبر منطق المحاكاة ببيانات مولّدة، **ماشي أرباح حقيقية وماشي أداء تاريخي للسوق**.
- `backtest`: كيقرأ بيانات Binance Futures التاريخية الحقيقية ويبني صفقات ورقية بناءً عليها، لكن فيه افتراضات مثالية عند إغلاق الشموع.
- `once`: كيعالج آخر شمعة مغلقة فقط لكل زوج؛ ما يعاودش يتداول نفس الشمعة إذا شغلتيه ثاني.
- `loop`: كيبقى يراقب كل 75 ثانية وهو شغال، وكيعالج غير الشموع المغلقة الجديدة.

## مهم جداً

- `bot.py` **بوت محاكاة فقط**. `demo_trader.py` يقدر ينفذ أوامر على منصة Futures Demo التجريبية باستخدام مفاتيح تجريبية، ولكن ما يقدرش يتداول بأموال حقيقية. لا تشارك كلمات السر أو مفاتيح API.
- Binance Futures هو مصدر **بيانات فقط**. ما كاين حتى ضمان أن استراتيجية EMA+RSI رابحة. الاختبارات ما كتشملش التمويل (funding)، التصفية (liquidation)، تعذر التنفيذ ولا كل ظروف السيولة.
- المحاكاة كتفتح بالسعر ديال آخر شمعة مغلقة مع تزحلق افتراضي؛ هاد الشي تقدير، ماشي تنفيذ حقيقي قابل للتكرار بالضبط. إغلاق الوقف/الهدف داخل 15 دقيقة تقديري من OHLC، وكيعتبر الوقف أولاً إذا جوج توصلو ليهم فنفس الشمعة.
- إذا Binance API محجوب جغرافياً أو بسبب الشبكة، البوت **كيوقف تحليل الزوج وما كيخترعش الأسعار**. ما كيحوّلش تلقائياً لبيانات Spot.
- 24/24: تشغيل `loop` من الهاتف يمكن يوقف ملي Android كيسد التطبيقات فالخلفية. التشغيل الدائم محتاج خادم دائم وتخزين دائم، مشي استضافة موقع مجاني كينعس. ملفات الحالة خاصها تْتْحفظ.
- خاص اختبار ومراجعة مستقلة قبل التفكير في التداول الحقيقي، اللي ما كاينش فهاد المشروع. لاحظ أن تشغيل Demo يحتاج API keys من حساب Demo تحفظ فـ GitHub Actions Secrets فقط.

## باش يراقب بوحدو بلا ما تبقى فاتح الهاتف: GitHub Actions

ملف `.github/workflows/paper.yml` كيشغّل البوت تقريباً كل 15 دقيقة (ليس مضمونا بالثانية، GitHub يقدر يأخر المهام)، وكيحفظ الحالة والتقارير داخل المستودع. **حتى فهاد الوضع ما كيدير أي تداول حقيقي نهائياً**.

1. إنشاء **مستودع جديد مستقل** باسم `ATLAS-PAPER-BOT` على GitHub. ما تخلطوش مع مشاريع أخرى.
2. رفع الملفات الموجودة فهاد ZIP لجذر المستودع، بما فيها `.github/workflows/paper.yml`.
3. من Actions تتأكد من تشغيل **ATLAS Paper Bot (NO REAL MONEY)**، وتسمح لـ Workflow بالكتابة إذا الحساب منع هاد الشي: Settings → Actions → General → Workflow permissions → Read and write permissions (إلا متاحة). أذونات `contents: write` ما كتساويش إعطاء صلاحيات فلوس، كتعطي البوت غير إمكانية كتابة حالة المحاكاة فالمستودع.
4. النتائج كتظهر فـ `data/summary.json` والصفقات المغلقة فـ `data/summary.csv`. إلا API ديال Binance ترفض GitHub runners حسب المنطقة، التشغيل غادي يفشل بأمان بلا اختلاق أسعار أو صفقات.
5. لإيقاف البوت: من Actions → ATLAS Paper Bot → Disable workflow. إن ما تفعّلش GitHub Actions أو وقفها، البوت ما غاديش يخدم 24/24.

**تنبيه:** GitHub Actions طريقة مجانية تقريبية للنسخة التجريبية، ماشي خادم مضمون أو نظام تداول إنتاجي. التشغيلات المجدولة يمكن تتأخر أو تتوقف. بغينا خدمة 24/24 بدقة أكثر، خاصنا خادم دائم وتخزين دائم.
