# ATLAS LIVE — ربط الحساب الحقيقي للقراءة فقط (مرحلة الأمان الأولى)

**الهدف:** التحضير لمراجعة معلومات حساب Binance الحقيقي بدون شراء/بيع، بدون إلغاء أوامر، وبدون تداول آلي.

## شنو تبدّل؟

- `live_readonly.py` وحدة **مستقلة**: ماشي `demo_trader.py` وماشي خدمة تداول.
- عنوان Binance Futures الحقيقي ثابت `https://fapi.binance.com`، ومسموح فقط بطرق **GET** على:
  - `/fapi/v1/time` للتحقق من الوقت العام
  - `/fapi/v3/account` لبيانات حساب USD-M Futures
  - `/fapi/v3/positionRisk` لقراءة المراكز المفتوحة
- أي مسار آخر ممنوع بالكود، واتباع redirects ممنوع كذلك. **ما كاين حتى POST أو DELETE أو PUT أو أوامر تداول**.
- HMAC SHA256 على الطلبات الموقّعة. رسائل الفشل لا تكشف المفتاح أو الرابط الموقّع أو محتوى رد Binance.
- الوضع الافتراضي `check`: النجاح/الفشل ونوع وضع الأصول، **بلا طبع رصيدك**.
- `local-summary`: عدد الأصول بأرصدة غير صفرية وعدد المراكز المفتوحة فقط. تجنّب إرساله كسجل عام.

## الحالة الفعلية — 17 أكتوبر 2026

- تمت إضافة الكود واختبارات بدون اتصال أو مفاتيح حقيقية إلى GitHub.
- **ما تمش ربط حساب Binance الحقيقي**، ولا تشغيل أي API على الحساب الحقيقي، ولا إنشاء مفتاح API نيابة عنك.
- الاندماج الرسمي ديال Binance مع ChatGPT يعطي **بيانات سوق عمومية فقط**، وليس حق الولوج لبيانات حسابك الخاص أو فتح الصفقات.
- مازال ما عندناش **خادم مؤكّد ومسموح له باتصال حساب Binance**، ولا نتائج تنفيذ موثّقة على Binance Demo. خوادم GitHub وRailway سبق رجّعات HTTP 451 على Binance Demo.
- لا تضف مفاتيح الحساب الحقيقي إلى مستودع GitHub العمومي أو إلى `Railway` أو المحادثة **حاليا**.
- لا تفعّل أي صلاحية تداول Spot/Futures/Margin أو سحب الأموال لأي مفتاح نحضّروه للقراءة.

## شنو خاص من بعد؟

1. نتحققو من صلاحية **USER_DATA / Read Only** لحسابك الحقيقي، ومن القيود القانونية والجغرافية لحسابك وعنوان IP اللي غادي يخدم الروبوت.
2. نختارو مكان تنفيذ موثوق ومسموح له الوصول، مع إعدادات سرية خارج الكود وبأقل صلاحيات. تجربة الخادم أولاً مع `/fapi/v1/time` **بدون أي مفتاح**.
3. من بعد ما تتأكد أنت من صلاحية الوصول، أنشئ **مفتاح API جديد مستقل للقراءة فقط** في Binance، بلا تداول وبلا تحويل وبلا سحب وبـ IP allowlist إن أمكن. ما تصيفطش المفاتيح لChatGPT ولا تحطها في ملفات GitHub أو صور.
4. فبيئة تشغيل آمنة ومحلية فقط، يقدر مستخدم متمكّن يضبط:
   - `ATLAS_LIVE_RO_KEY`
   - `ATLAS_LIVE_RO_SECRET`

   ومن بعد يشغل `python live_readonly.py --mode check`. لا تفعل هذه الخطوة إلا بعد موافقة واضحة على البيئة الآمنة واختبار قابلية الاتصال.

5. **التداول الحقيقي مازال ممنوع** بهاذ النسخة؛ خاص backtest خارج العينة، اختبارات Demo معمّقة، تخزين دائم، مصادقة وإقفال قوي، حد خسارة، تسوية أوامر وتعامل مع فشل وقف الخسارة، وموافقة جديدة مستقلة من صاحب الحساب.

هذه النسخة تقرأ الحساب فقط. حتى مفتاح Read Only يمكن يكشف معلومات حساسة: حافظ عليه بنفس حذر كلمة السر. وأي تنفيذ أرباح مستقبلية غير مضمون.

مرجع Binance الرسمي: https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/account
